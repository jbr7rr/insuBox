# Contributing to InsuBox

We appreciate your interest in contributing to InsuBox! Whether you're fixing bugs, adding features, or improving documentation, your contributions help make InsuBox better.

## How to Contribute

### 1. Fork and Clone
- Fork the repository to your GitHub account.
- Clone the forked repository to your local machine.
- Set up your development environment according to the project's documentation.

### 2. Creating a Pull Request (PR)
Each PR must include:
- A **clear and concise description** of what is implemented and why.
- **Proof of function**, including:
  - **Unit tests** for new code where applicable.
  - **Integration tests** if your change affects multiple components.
  
### 3. Code Style and Quality
All contributions must adhere to the project's coding style. The Continuous Integration (CI) system will check:
- **Coding style compliance**
- **Sanity check builds**
- **Documentation builds**

#### Clang-Format
The project provides a `.clang-format` file. **All code must be formatted using clang-format before submission.** This ensures consistency across the codebase.

By contributing to this project, you agree that:

## Need Help?
If you have any questions, feel free to open a discussion or reach out via the project's issue tracker.
