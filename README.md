# InsuBox

## Description

**This software is still in development, it's not ready for use.**

InsuBox is Artificial Pancreas system (APS) which targets embedded systems, so the hardware size can be minimized. It uses ZephyrOS as a base and can run a variety of hardware.

Intended use case is as a stand-alone loop system, so one doesn't need to carry a phone to run the loop. The system can be configured and monitored via Bluetooth from a phone.

In-depth documentation can be found in the `doc` folder.  
Build of the latest documentation can be found [here](https://jbr7rr.github.io/insuBox/).
